# Security policy

Please do not disclose suspected vulnerabilities in a public issue.

GitHub private vulnerability reporting was checked on 2026-09-11 and is currently
disabled. Until the maintainer enables it, a public issue may request a private
reporting channel without describing the vulnerability. Do not submit vulnerability
details through that public request. When enabled, use the repository's Security
tab to report privately.

Never include secrets, production data, or working exploit payloads in reports.

## Supported versions

This project is pre-release. Security fixes target the current main source;
there is no maintained release branch or published-binary support commitment yet.
The `v0.2.0` Git tag does not establish public Maven availability. A supported
release matrix and verified private reporting channel are publication gates in
[the release checklist](docs/releasing.md).
