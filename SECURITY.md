# Security policy

Please do not disclose suspected vulnerabilities in a public issue.

GitHub private vulnerability reporting was enabled and verified on 2026-09-22.
Use [Report a vulnerability](https://github.com/mat973252-coder/agent-permit4j/security/advisories/new)
or the repository's Security tab to report privately.

Never include secrets, production data, or working exploit payloads in reports.

## Supported versions

Version 0.5.0 is prepared but not yet published. Security fixes target current main;
after publication, only the latest 0.5.x patch release will receive security fixes.
Older pre-release tags are unsupported.
The `v0.2.0` Git tag does not establish public Maven availability. A supported
release matrix and verified private reporting channel are publication gates in
[the release checklist](docs/releasing.md).
